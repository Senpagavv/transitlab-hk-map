# 香港分区数据地图使用说明

[打开地图](https://senpagavv.github.io/transitlab-hk-map/)。在右上角选择「中文」。初始图层显示 2026 年估算人口密度，颜色越深，单位面积的估算居民越多。图例右侧的数字是落入该颜色区间的分区数。

## 从启德开始

1. 点「查看启德站一带」，也可以搜分区编号 `286.2`。搜索站名会移动地图，点选分区后可看该区详情。
2. 启德站一带的 2021 年分配人口为 **30,034 人**，2026 年估算为 **84,141 人**。这是整个模型分区的人口。放大地图或点附近分区，可以直接比较。
3. 分别切换「人口总数」「人口密度」「人口变化」，观察总量、单位面积人数和变化幅度的区别。其他图层还有长者占比、岗位密度、工作日到达出行和学额。
4. 地图标签会按缩放和屏幕空间自动避让。需要对照道路时可打开「详细街道底图」。在手机上点「选择图层」，点选区域后下方显示详情。
5. 在详情栏下载 CSV 或 GeoJSON。Excel 导入时把 `zone`、`parent` 设为文本。QGIS 可直接打开 GeoJSON。表里保留真实零值，缺失的百分比留空。

## 数据从哪里来

2021 年香港人口普查提供 211 个母区的人口及年龄结构。原模型按铁路站点等要素细分为 455 区，并按住宅楼面分配人口。母区先按规划署分区预测的增长比例向前推算，再按地区年龄结构变化调整，最后用统计处 2026 年中临时人口估计校准到陆上人口口径。小区按各自 2021 年分配人数占母区的比重取得整数人数。地图密度采用原模型面积。显示边界已经简化，只用于制图。

岗位、工作日出行和学额来自已保存的原模型结果。全港总量能核对，不代表每个小区的真实人口都已独立测量。[逐层字段、上游资料与方法](methods.md) · [使用与署名](../USE.md)。

## 在自己的电脑复现

下载仓库，进入根目录。先用 Python 3.10 或以上版本运行 `python scripts/build_map.py`。脚本用随附的母区控制数和小区权重重算人口，输出 455 区的 CSV 和 GeoJSON。全港估算合计应为 **7,517,309**。然后用 Node.js 24 运行 `npm ci` 和 `npm run dev`，打开终端显示的地址。运行 `npm run build` 可生成可静态部署的 `dist/` 目录。
